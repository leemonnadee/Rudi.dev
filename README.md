   ```bash

   ```

2. Open the project directory:

   ```bash
   cd Rudi.io
   ```

3. Open `index.html` in your browser.

## Deployment

This is a static website and can be hosted on services such as **Vercel** or **GitHub Pages**.

### Deploy with Vercel

1. Import `leemonnadee/Rudi.io` into [Vercel](https://vercel.com/).
2. Configure it as a static site if prompted. No build command is needed for the current HTML/CSS/JavaScript setup.
3. Set the output directory to the repository root (`.`) if Vercel asks for one.
4. Deploy and confirm that the live domain matches the canonical URL configured in `index.html`.

After pushing updates to the connected GitHub branch, Vercel can redeploy the site automatically.

## SEO Notes

The page includes basic metadata for search engines, including a page title, description, canonical URL, and Open Graph fields. To keep these signals consistent:

- Use your actual production domain in the canonical URL and Open Graph URL.
- Set `og:image` to an actual preview image URL rather than the homepage URL.
- Keep only one primary meta description in `index.html`.
- Add a `robots.txt` and `sitemap.xml` using the production domain if you want to make crawling guidance and page discovery clearer.
- Register the site with [Google Search Console](https://search.google.com/search-console/) and submit the sitemap when available.

Search engines may take time to crawl and index a new or updated site; metadata alone does not guarantee rankings.
